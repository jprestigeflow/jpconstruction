# Setting up the "J Prestige Construction" project in the Claude app

1. **Create the project.** Claude app → Projects → New project → name it `J Prestige Construction`. Description: "Marketing + ops for Roman Jano's contracting business (JPC)."
2. **Paste the instructions.** Open the project → Set project instructions → paste the whole of `instructions.md`.
3. **Upload knowledge.** Project knowledge → Add content → upload `knowledge-jpc.md`. Also upload `brand/jpc-wordmark-black.png` and, once live, a screenshot of the homepage so Claude can see the look.
4. **Pick the model.** Use the default best model for planning and copy; switch to a faster model for quick caption edits.
5. **First prompt to try:** "Write post 2 of the 30-post plan: an Education post on what a real estimate includes. Give me the static headline, the video script with timings, IG/FB caption, TikTok caption and hashtags."

Keep `knowledge-jpc.md` updated when facts change (new domain, real photos, confirmed testimonials) and re-upload.
